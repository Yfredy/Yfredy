关于我

About Me

我是 姚越，南京大学音频声学硕士，深耕 AI 大模型加速推理、智能体开发、边缘 AI、AI 终端与具身智能方向。从空间音频引擎的 C99/Android NDK 实时渲染，到 QNN NPU 边缘部署的 INT8 量化与 fp16 精度修复，再到多智能体协作平台的 Coordinator Mode 落地，习惯于在「算法理论 ↔ 工程落地」的闭环中打磨每一处细节。

技术上偏好 用确定性替代精度敏感的预测、用绕过而非修复换取稳定可用 的工程决策，主导过 vLLM 并发架构重构（TTFA ↓40%）、自研 radix-2 FFT 实现 29.5× 实时空间音频、为 Qwen3-Omni-30B AWQ-8bit 量化大模型搭建眼镜端 SSE 流式链路。9 个项目覆盖智能体、边缘 AI、TTS/ASR、多模态、音频工程、医学影像六大方向。

技术栈覆盖 Python / PyTorch / vLLM / FastAPI / Android Kotlin / QNN SDK / ONNX / Docker / K8s，既能写守护线程持锁循环驱动 vLLM step() 的并发架构，也能手工拼装 44 字节 WAV header 完成 OpenAI 多模态 audio_url 上行。相信「层层兜底」的工程哲学，喜欢在 NPU 部署、流式协议、并发闸门这些底层细节里找性能与稳定性的平衡点。

除工程实践外，长期关注 语音情感识别、多模态大模型推理优化、边缘 AI 部署与量化、音频空间化与 HRTF 四个学术研究方向，参与国家重点研发项目《多模态光声成像》《光声高速传输成像》等课题，以第一作者发表 SCI 二区 top 期刊 3 篇（《Optics Letters》《Physical Review Applied》《Optics Express》）与发明专利 1 项，并积极投身开源社区，在 GitHub 维护 scientific-illustrator、drawio-scientific-illustrator、claw-code、matrix-live-diarizer、KuralNet、SER、Speech-Emo-Rec 等 13+ 仓库。

研究方向

Research Interests

语音情感识别

Speech Emotion Recognition (SER)

研究 TIM-Net / LIGHT-SERNET 等语音情感识别模型在边缘 NPU 上的部署与量化，从 TensorFlow 训练到 QNN INT8 量化到 Hexagon NPU 推理的端到端链路，关注 INT8 量化对情感特征敏感度的保持与精度-性能权衡。

多模态大模型推理优化

Multimodal LLM Inference Optimization

研究 Qwen3-Omni-30B 等多模态大模型在边缘 GPU（Jetson）上的 AWQ-8bit 量化部署，vLLM 并发架构重构（守护线程持锁循环驱动 step()），SSE 流式协议工程化与协程背压优化。

边缘 AI 部署与量化

Edge AI Deployment & Quantization

研究 Qualcomm QNN SDK、Hexagon HTP v73 NPU 上 precompiled context binary 静态推理链路，fp16 精度崩塌根因分析与「绕过而非修复」工程决策，DSP 内存约束下的模型静态化方案。

音频空间化与 HRTF

Audio Spatialization & HRTF

研究基于 HRTF 的实时双耳空间音频渲染引擎，自研 radix-2 FFT 与分区 FFT 卷积（overlap-add）实现 29.5× 实时，头部追踪 IMU 平滑与双线性 HRTF 插值消除切换咔嗒声，5.1/7.1 环绕声下混。

多智能体协作与编排

Multi-Agent Collaboration

研究基于 Claude Agent SDK 的多智能体协作平台，Coordinator Mode 规划-指派-综合-审查四阶段工作流，CommHub 通信中枢（inbox/outbox + 文件租约）解决并行编辑冲突，AG-UI 协议 SSE 事件流工程化。

医学影像组学与临床建模

Medical Radiomics & Clinical Modeling

研究 SPECT 心肌灌注显像 IBSI 合规特征提取流水线（106 例 × 1130 特征），7 大类 30+ 算法系统比较与多模态融合（AUC 0.736 → 0.905），小样本高维场景下的稳健建模方法论。
